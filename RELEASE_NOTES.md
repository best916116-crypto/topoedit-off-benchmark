# Release notes v0.67D.1

This is a repo-friendly GitHub release package for TopoEdit-Off.

Compared with internal project outputs, filenames and directory names have been simplified for external users. Step-numbered filenames are not used in the GitHub-facing data tree.

Included:
- benchmark summaries;
- figure-source TSVs;
- validation-panel resources;
- hard-split summaries;
- role/claim gates;
- release metadata;
- minimal demo.

Excluded:
- raw data;
- transient FASTQ/BAM/SRA/intermediate files;
- draft figures;
- internal runbooks and failed/superseded outputs;
- large derived candidate-level tables.
